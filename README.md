# Sloane's Closet

Save clothes from any online store, see yourself wearing them, and tap through to buy.

See `CLAUDE.md` for how the app is built, `BACKLOG.md` for what's next, and `DECISIONS.md` for why things are the way they are.

## Run it locally

1. `npm install`
2. Copy `.env.example` to `.env.local` and fill in the values (never commit it).
3. `npm run dev`
